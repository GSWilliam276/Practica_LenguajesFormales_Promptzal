PromptZal - Analizador Léxico

Analizador léxico para el lenguaje PromptZal, desarrollado como práctica 
del Curso de Lenguajes Formales y de Programación.

Tecnologías

- Java 17
- Apache Maven
- HTML (para los reportes generados de tokens y errores léxicos)

Cómo ejecutar

1. Compilar con Maven y ejecutar el `.jar`, o correr desde NetBeans
2. Seleccionar el archivo `.pz` a analizar desde la ventana que se abre
